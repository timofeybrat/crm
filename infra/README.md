# Инфраструктура

Единая точка входа — `docker-compose.yml` в корне репозитория. Dockerfile каждого
приложения хранится рядом с его исходниками. Не дублируем Compose-конфигурации.

`docker compose up --build` запускает PostgreSQL, API и Next.js.
`docker compose --profile redis up --build` дополнительно запускает Redis.
Redis пока не используется приложением: кэш и очереди не нужны по ТЗ.

Порты публикуются только на localhost. Значения паролей по умолчанию предназначены
для локальной разработки. Для паролей со спецсимволами URL подключения должен
содержать percent-encoding; простая подстановка пароля в DATABASE_URL этого не делает.

Frontend в Compose использует development target. Production target Dockerfile
подготовлен отдельно; перед развёртыванием необходимо проверить его контейнерную сборку.
В production миграции запускаются отдельным шагом до запуска реплик API.
Локально единственный экземпляр backend запускает миграции перед Uvicorn.

После изменения кода повторить `docker compose up --build`; bind mounts пока не настроены.
Остановка: `docker compose down`. Данные сохраняются в именованных томах.
