# Задачи CRM

План оставшихся работ после инициализации проекта. Задачи расположены по убыванию
приоритета: сначала обязательный backend и его корректность, затем завершение
сдаваемого API, пользовательские сценарии frontend и итоговая проверка проекта.
Развитие видеосвязи после сдачи выделено в отдельный раздел; опциональные улучшения
находятся в самом низу. Внутри разделов порядок учитывает
зависимости; тесты добавляются вместе с функциональностью, а не после всего API.

Уже готовы: каркасы Next.js и FastAPI, FSD с `src/app/providers`, зависимости и
lock-файлы, SQLAlchemy-сессии, конфигурация Alembic, `/health`, `/ready`, два
инфраструктурных теста, Dockerfile и `docker-compose.yml`. Эти работы не повторяем.
Бизнес-модели, миграция и обязательные эндпоинты реализованы; текущие отметки ниже
отражают проверенные результаты. Frontend-сценарии реализованы и проверены
сквозными тестами; детали проверки — в verification.md.

ТЗ ограничивает работу четырьмя часами и не требует интерфейса. Frontend включён
в план по требованиям проекта, но идёт после обязательного API. Если работа
выполняется в рамках этого лимита, учитывать фактическое время и честно записать
незавершённые задачи в README. Redis остаётся необязательным сервисом.
